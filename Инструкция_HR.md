## 1. Как устроена система

В Битрикс24 работают два чат-бота.

| Бот | Кто пишет | Для чего |
|---|---|---|
| **Бот стандартов** | сотрудники | даёт документ, отвечает на вопросы по стандартам, проводит тест и экзамен |
| **HR-бот** | только HR-менеджеры | проверка и запуск курсов, приглашение сотрудников, роли, отчёты, реестр руководителей |

Командовать HR-ботом могут только HR-менеджеры из списка, который ведёт разработчик. Всем остальным бот отвечает «⛔ Команды HR-бота доступны только HR-менеджерам». Чтобы добавить или убрать HR-менеджера, напишите разработчику.

Основной цикл:

```
Документ в папке на Диске
  → бот составляет черновик курса с вопросами
  → HR проверяет вопросы и подтверждает курс
  → сотрудники получают курс: читают, сдают базовый тест и экзамен
  → HR получает результаты
```

**Кнопки.** Почти любое действие доступно кнопкой под сообщением бота. Кнопки есть только у последнего сообщения бота в чате: когда бот присылает новое сообщение, кнопки у предыдущего исчезают. Любую кнопку можно заменить командой, набранной текстом (раздел 9). Регистр букв в командах не важен.

**Главное меню HR-бота** приходит в ответ на «Меню» или на любое сообщение, которое бот не распознал как команду.

## 2. Первый курс за 5 шагов

1. Положите документ в папку «Регламент_тест2» на Диске. Аббревиатуры отделов пишутся в начале имени файла (раздел 3).
2. Дождитесь сообщения HR-бота «📄 Новый документ».
3. Нажмите «Вопросы N» и пролистайте вопросы. Неудачный вопрос исправьте кнопкой «✏️ Изменить» или пересоздайте кнопкой «🔄 Заново».
4. Нажмите «Подтвердить и запустить N». Сотрудники нужных отделов получат уведомление о курсе.
5. Пригласите сотрудников, которых ещё нет в системе: «Пригласить email», затем выберите роль.

## 3. Загрузка документов

### Куда класть

Папка «Регламент_тест2» на Диске Битрикс24. Бот проверяет её каждые 30 секунд, вместе с вложенными папками до 5 уровней.

Поддерживаемые форматы: **.docx, .pdf, .pptx, .txt, .md**. Файлы других форматов бот пропускает. Служебные файлы, имя которых начинается с точки (их создаёт macOS), бот сам убирает в корзину Диска.

### Как назвать файл

Кому адресован документ, бот определяет по аббревиатурам отделов в начале имени файла. Аббревиатуры пишутся через запятую:

```
FO, HSKP, ENG Вывод номера из обращения.docx   → приём и размещение, клининг, инженерная служба
ALL Конфиденциальность.docx                    → все сотрудники
Конфиденциальность.docx                        → все сотрудники (аббревиатур нет)
```

Сотрудники видят название без аббревиатур: «Вывод номера из обращения».

| Аббревиатура | Роль |
|---|---|
| FO | Служба приёма и размещения |
| RES | Отдел бронирования |
| GR | Работа с гостями |
| HSKP | Служба клининга и горничных |
| ENG | Инженерно-техническая служба |
| F&B | Питание |
| S&M, SAL | Отдел продаж и маркетинга |
| CAT | Банкеты и мероприятия |
| REV | Управление доходностью |
| PR | Связи с медиа и PR |
| ADM | Администрация |
| HR | Отдел кадров |
| FIN | Финансы и учёт |
| PUR | Закупки и снабжение |
| IT | IT-поддержка |
| SEC | Охрана и безопасность |
| ALL | Все сотрудники |

Актуальный список всегда можно получить командой «Аббревиатура».

Если после известной аббревиатуры стоит незнакомая латинская, например «FO, HSPK Уборка.docx», это похоже на опечатку. Бот предупредит об этом в сообщении «Новый документ». Проверьте имя файла.

**Правка списка аббревиатур:**

- «Аббревиатура» — показать список.
- «Аббревиатура добавить FIN Финансовая служба» — добавить аббревиатуру и создать роль с этим названием.
- «Аббревиатура удалить FIN» — убрать аббревиатуру. Сама роль остаётся.

Аббревиатура состоит из латиницы и цифр, не длиннее 6 символов. Знак «&» через бота добавить нельзя (F&B и S&M уже есть в списке). Привязать новую аббревиатуру к уже существующей роли через бота тоже нельзя: для этого напишите разработчику.

### Что происходит после загрузки

1. Бот читает документ и составляет вопросы. Их число зависит от объёма документа: в базовом тесте от 2 до 5, в экзамене от 3 до 10.
2. **Сразу же**, до подтверждения курса, приглашённые сотрудники нужных отделов получают сообщение «📄 Новый стандарт доступен» со ссылкой. Документ можно читать и задавать по нему вопросы боту. Тест им пока не назначен.
3. HR получает сообщение «📄 Новый документ»: сколько в курсе вопросов и сколько сотрудников получат рассылку после подтверждения. Под ним кнопки «Вопросы N» и «Подтвердить и запустить N».

### Обновление документа

Загрузите новую версию **с тем же именем в ту же папку**: заменой файла или удалив старый и загрузив новый. Бот обновит текст для поиска и пришлёт «🔄 Документ обновлён: N фрагментов (было M). Вопросы курса сохранены».

Вопросы при обновлении **не пересоздаются**. Если содержание изменилось существенно, пересоздайте их командой «Перегенерировать N» (раздел 4).

Файл под другим именем, но с тем же содержимым бот привяжет к существующему курсу и сообщит: «то же содержимое, что у курса…, новый курс не создан».

### Удаление документа

Удалите файл из папки. Примерно через минуту бот уберёт документ из поиска и пришлёт «🗑 Документ удалён из папки». Курс уходит в архив: новым сотрудникам он больше не назначается. Результаты тех, кто уже проходил курс, остаются в отчётах.

Отдельной команды «снять курс» нет: курс снимается удалением документа.

### Ограничения

- **Размер файла — до 1024 МБ.** Если файл больше, курс не создаётся, а HR получает сообщение. Обычно вес дают вставленные видео и картинки: выложите облегчённую версию, бот подхватит её сам.
- **3 неудачные попытки обработки.** Если обработка сорвалась 3 раза подряд, бот перестаёт пробовать и пишет HR. Загрузите документ заново или другой версией, и попытки начнутся с нуля.

## 4. Проверка вопросов и запуск курса

### Курсы на проверке

«📚 Курсы на проверке» (команда «Курсы») — все курсы, которые ждут подтверждения, по 8 на страницу. Рядом с каждым курсом кнопки «Вопросы N» и «Подтвердить N».

### Просмотр вопросов

- «Вопросы 12» — вопросы курса №12 карточками по одному, листать кнопками «⬅️ Назад» и «▶️ Далее». Правильный вариант на карточке отмечен ✅.
- «Вопросы 12.6» — сразу шестой вопрос.
- «Вопросы 12 все» — все вопросы с правильными ответами одним сообщением.

Нумерация сквозная: сначала вопросы базового теста, потом экзамена. Если в курсе 5 базовых и 10 экзаменационных вопросов, то вопросы 1–5 относятся к базовому тесту, а 6–15 к экзамену.

### Правка вопроса

Нажмите «✏️ Изменить» под карточкой или напишите «Изменить 12.6» (можно «Изменить 12 6»). Бот пришлёт вопрос в виде, удобном для копирования:

```
Текст вопроса
A. первый вариант
B. второй вариант
C. третий вариант
D. четвёртый вариант
Ответ: A
Пояснение: почему этот ответ верный
```

Скопируйте, исправьте и пришлите **одним сообщением**. Менять всё не обязательно:

| Что прислать | Что изменится |
|---|---|
| `B. новый текст варианта` | только вариант B |
| `Ответ: C` | только правильный ответ |
| `Пояснение: …` | только пояснение |
| одна строка без буквы в начале | только текст вопроса |

Остальное останется как было. Русские буквы А, В, С, Д бот тоже понимает. После сохранения бот покажет вопрос так, как его увидит сотрудник.

- «✏️ По шагам» — правка по одному полю: текст, варианты A–D, правильный ответ. Точка «.» оставляет поле без изменений.
- «Отмена» — выйти без изменений.

Число вопросов в курсе при правке не меняется. Правка сохраняется сразу, и в курсе на проверке, и в уже запущенном.

На ответ у бота 10 минут. Если за это время ничего не прислать, правка сбрасывается, и команду нужно повторить.

### Пересоздание вопросов

- «🔄 Заново» под карточкой или «Перегенерировать 12.6» — новый вариант одного вопроса.
- «Перегенерировать 12» — пересоздать **все** вопросы курса. **Все ручные правки этого курса будут потеряны.**

Результат бот пришлёт отдельным сообщением, когда закончит.

### Подтверждение и запуск

«Подтвердить и запустить 12» (команда «Подтвердить 12»). Курс становится активным, и бот сразу рассылает уведомления сотрудникам, у которых выполнены три условия:

- HR пригласил их в обучение;
- их роль совпадает с отделами курса или курс адресован всем;
- этот курс ещё не пройден.

Свободные сотрудники получают «📚 Тебе доступен новый курс» с кнопкой «▶ Начать обучение». Те, кто сейчас проходит другой курс, получают «📚 Добавлен новый курс»: он ждёт их в разделе «Мои курсы». В обоих сообщениях есть ссылка на документ и срок: 7 дней.

**Подтверждение отменить нельзя.** Проверьте вопросы до нажатия.

## 5. Приглашение сотрудников и роли

Бот стандартов обучает только приглашённых сотрудников. Остальным он отвечает: «🔒 Доступ к обучению открывает HR-менеджер».

### Пригласить сотрудника

1. Нажмите «✉️ Пригласить сотрудника» и следующим сообщением напишите, кого пригласить. Можно и одной строкой: «Пригласить i.ivanova@example.ru».
2. Кого искать — любым из способов:
   - **email** — как в профиле Битрикса;
   - **ID сотрудника** — число из адреса профиля (например, 54824), подходит для тех, у кого нет почты;
   - **фамилия** — «Пригласить Саркисян». Если совпадений несколько, бот покажет кандидатов кнопками;
   - **несколько человек** — через запятую или с новой строки: «ivan@…, 54824, Петров». Роль спрашивается один раз для всех;
   - **отдел целиком** — название отдела как в Битриксе (например, «Ресепшн» или «отдел Ресепшн»). Если по фамилии никого нет, бот ищет отдел, показывает, кто из него ещё не приглашён, и кнопку «Пригласить всех». Служебные учётки и уже приглашённые пропускаются.
3. Выберите роль цифрой или кнопкой. «Отмена» — не приглашать.
4. Сотрудник получает первое сообщение от бота со ссылкой на документ первого подходящего курса.

Что может ответить бот:

| Ответ | Что значит |
|---|---|
| «✅ … приглашён — отправил ему первое сообщение» | всё в порядке, обучение началось |
| «Курсов для этой роли пока нет» | доступ выдан; сотрудник получит уведомление, когда появится подходящий курс |
| «Активных курсов нет» | доступ выдан, но ни одного запущенного курса пока нет |
| «ℹ️ … уже проходит обучение (роль: …)» | повторное приглашение роль не меняет; для смены роли используйте «Роль email» |
| «⚠️ «…» — не найден в Битриксе» | проверьте адрес, ID или написание фамилии |
| «🔎 По «…» несколько сотрудников — выбери» | нажмите нужного кандидата |
| «⚠️ Поиск по отделам недоступен: у вебхука бота нет права «department»» | право добавляет разработчик в настройках вебхука |

На выбор роли даётся 10 минут. Если за это время отправить другую команду, выбор отменится, и бот напишет, что приглашение не завершено.

### Сменить роль

Напишите «Роль» и следующим сообщением email или ID сотрудника (или сразу «Роль i.ivanova@example.ru»), затем выберите новую роль цифрой. Текущий курс сотрудник доучивает по старой роли, следующие курсы назначаются по новой. Сотрудник получает сообщение «HR назначил тебе роль…».

Сменить роль может только HR.

### Что даёт роль

Роль определяет, какие курсы назначаются сотруднику и какие документы он видит в разделе «Документы» и в ответах бота.

- Сотрудник видит документы своего отдела и общие (с аббревиатурой ALL или без аббревиатур).
- Роль **«Менеджер (доступ ко всем стандартам)»** видит документы и курсы всех отделов.
- Полный список ролей бот показывает при приглашении.

### Допустить к экзамену

Сейчас эта команда нужна редко. После сдачи базового теста сотрудник допускается к экзамену автоматически. «Допустить email» пригодится, только если в статусе сотрудника написано «ждёт допуска к экзамену». Такое бывает у обучений, начатых до перехода на автоматический допуск.

## 6. Как проходит обучение сотрудник

Этот раздел поможет отвечать на вопросы сотрудников.

1. **Чтение.** Бот присылает ссылку на документ. По стандартам можно задавать боту вопросы: он отвечает по их текстам.
2. **Базовый тест.** Начинается кнопкой «✅ Готов к тесту». Проходной порог 60%, например 3 из 5. Если тест не сдан, бот возвращает сотрудника к чтению, и тест можно пройти заново. HR получает уведомление и при сдаче, и при провале.
3. **Экзамен.** После сдачи базового теста сотрудник допущен к экзамену автоматически и начинает его кнопкой «🎓 Начать экзамен», когда будет готов. Проходной порог 70%, например 7 из 10.
4. **Итог.** Сотрудник видит результат, а HR получает сообщение с баллами за базовый тест и экзамен и отметкой «✅ Сдан» или «❌ Не сдан».
5. **Пересдача.** Кнопка «🔁 Пересдать экзамен». Число пересдач не ограничено.

После каждого ответа сотрудник сразу видит, верен ли ответ, правильный вариант и пояснение.

**Что ещё полезно знать:**

- **Варианты ответов перемешаны** у каждого сотрудника по-своему, а при пересдаче порядок меняется. Поэтому буква, которую выбрал сотрудник, может не совпадать с буквой в карточке вопроса у HR. В «Истории» ответы показаны в буквах карточки HR.
- **Пауза.** «⏸ Отложить тест» или «⏸ Отложить экзамен» сохраняет прогресс, а «▶ Продолжить» возвращает к тому же вопросу. Нажатие буквы во время паузы не засчитывается.
- **Вопросы во время теста.** Бот отвечает на вопросы по стандартам и во время теста, но не по документу, по которому идёт проверка.
- **Несколько курсов.** «📚 Мои курсы» показывает список курсов со статусами, а «Выбрать N» переключает на другой курс. Прогресс оставленного курса сохраняется. Если у сотрудника больше одного курса, кнопка «✅ Готов к тесту» сначала спрашивает, по какому курсу начинать тест, и показывает курсы кнопками.
- **«📄 Документы»** — стандарты отдела сотрудника и общие стандарты со ссылками.
- **«❓ Помощь»** — подсказка по командам.
- Курсы назначаются в порядке запуска: сотрудник получает первый непройденный курс, подходящий его роли.

## 7. Сроки, напоминания и эскалации

### Срок

На каждый курс даётся **7 дней**. Отсчёт идёт от более поздней из двух дат: запуска курса или приглашения сотрудника. Для курсов, запущенных до включения сроков, отсчёт идёт с даты включения.

Курс закрывается сдачей экзамена. Несданный экзамен курс не закрывает: срок продолжает идти, а сотруднику предлагается пересдать.

### Напоминания сотруднику

Каждое утро, между 9:00 и 10:00 по Москве, сотрудник получает список незакрытых курсов с оставшимся сроком: «осталось 3 дн.», «сегодня — последний день», «просрочен на 2 дн.».

### Эскалации руководителям

Эскалация приходит руководителю сообщением от HR-бота в чат Битрикса.

| Ступень | Когда | Кому |
|---|---|---|
| 1 | курс не пройден за 7 дней | руководители из реестра |
| 2 | курс не пройден за 14 дней | старшие руководители; если старших нет — обычные |

Каждая ступень по паре «сотрудник + курс» отправляется один раз. В сообщении указаны ФИО, должность, курс, этап обучения и дата истёкшего срока.

Реестр руководителей общий: эскалация уходит всем руководителям нужного уровня, без привязки к отделу сотрудника.

HR получает копию эскалации, если:

- реестр руководителей пуст;
- кого-то из руководителей не удалось найти на портале по email;
- старших руководителей в реестре нет.

### Реестр руководителей

- «👥 Руководители» — список получателей эскалаций.
- «⚙️ Править руководителей» → «➕ Добавить» или «➖ Удалить», затем следующим сообщением email. Для старшего руководителя (ступень 2) допишите слово «старший»: «petrov@example.ru старший».
- Те же действия одной строкой: «Руководитель добавить petrov@example.ru [старший]», «Руководитель удалить petrov@example.ru».

Email руководителя должен совпадать с адресом в его профиле Битрикса.

## 8. Отчёты и история

### Отчёт по обучению

Кнопка «📊 Отчёт по обучению» или команда «Отчёт». Бот присылает два ответа.

1. **Сводку текстом:** последние 30 обучений, сгруппированные по ролям. В строке указаны сотрудник, должность, email, курс, этап и дата.
2. **Ссылку на файл «Отчёт по обучению ГГГГ-ММ-ДД.xlsx»** и на папку отчётов на Диске. Каждый запуск создаёт новый файл с датой, старые отчёты остаются в папке.

В файле три листа.

- **«Матрица»:** строки — сотрудники, столбцы — курсы. В ячейке текст и цвет:
  - **Сдан 7/10** (зелёный) — экзамен сдан, лучший результат из попыток
  - **Не сдан 3/10** (красный) — последняя попытка провалена
  - **Идёт** (жёлтый) — курс начат: читает, проходит тест, на паузе или ждёт допуска
  - пустая ячейка — сотрудник курс не начинал
  В шапке включён фильтр Excel: можно отобрать сотрудников по отделу, должности или роли. Колонка «Отдел» заполняется названиями отделов Битрикса; пока у вебхука нет права «department», там ID отдела.
- **«Детали»:** каждое обучение отдельной строкой с отделом, курсом, статусом (тем же текстом и цветом), баллами за базовый тест и экзамен и датой. Фильтр тоже включён.
- **«Легенда»:** расшифровка статусов и цветов.

Этапы в отчётах: изучает материал · проходит базовый тест · базовый тест на паузе · допущен к экзамену · сдаёт экзамен · экзамен на паузе · ждёт допуска к экзамену · завершил — ✅ сдан или ❌ не сдан (с баллами).

### История сотрудника

Кнопка «📋 История сотрудника» или команда «История i.ivanova@example.ru» (можно ID сотрудника). Бот показывает последние 3 обучения сотрудника со всеми ответами. По каждому ответу видны номер вопроса, ✓ или ✗, начало текста вопроса, ответ сотрудника и верный ответ. Буквы указаны так, как в карточке вопроса у HR.

ID сотрудника указан в уведомлениях HR-бота о результатах, например «(ID: 500)».

## 10. Если что-то пошло не так

| Что видно | Почему | Что делать |
|---|---|---|
| Бот не ответил на повторно отправленное сообщение | одинаковое сообщение в течение 15 секунд бот считает дублем | дождитесь ответа на первое сообщение |
| После загрузки не пришло «Новый документ» | формат не поддерживается; имя файла начинается с точки; файл уже обработан (обновление приходит как «Документ обновлён»); содержимое совпало с другим курсом (придёт отдельное сообщение) | проверьте формат и имя файла; если за несколько минут ничего не пришло, напишите разработчику |
| «…больше лимита 1024 МБ» | тяжёлый файл, обычно из-за видео | выложите облегчённую версию |
| «…обработка сорвалась 3 раза подряд» | файл не удаётся разобрать | загрузите документ заново или другой версией |
| «⚠️ Возможная опечатка в префиксе» | незнакомая аббревиатура в имени файла | переименуйте файл |
| «⚠️ Сотрудник с email … не найден в Битриксе» | адрес не совпадает с профилем или сотрудник неактивен | проверьте профиль сотрудника |
| «⚠️ … не найден среди приглашённых» | сотрудник ещё не приглашён | сначала «Пригласить email» |
| «👀 Сотрудник … запросил обучение — подходящих активных курсов нет» | для роли сотрудника нет запущенного курса | запустите курс или проверьте роль сотрудника и аббревиатуры в имени файла |
| Сотрудник не видит документ своего отдела | другая роль или нет нужной аббревиатуры в имени файла | «Роль email» или переименуйте файл |
| Выбор роли или правка вопроса «слетели» | прошло 10 минут или отправлена другая команда | повторите команду |
| Пропала кнопка под старым сообщением | кнопки есть только у последнего сообщения бота | напишите «Меню» |

## 11. Что пока не включено

Эти функции в системе есть, но на портале сейчас выключены или ждут данных. Чтобы включить их, напишите разработчику.

- **Автоматическая роль по отделу Битрикса.** Нужна таблица соответствия «отдел Битрикса → роль». Пока роль назначает HR при приглашении.
- **Уведомления HR о новых сотрудниках и переводах между отделами.** Не задан список отделов для отслеживания.
- **Еженедельный рейтинг лучших в Ленте.** Выключен, чтобы не засорять общую Ленту. Штатная «Благодарность» с медалью за сданный экзамен включена: пост видит только сам сотрудник, медаль в профиле видна всем.
- **Эскалации по электронной почте.** Пока эскалации приходят только в чат Битрикса.
